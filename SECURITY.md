# Security Policy

This code is pre-audit and is not production-ready. Do not use it with Mainnet
spending keys or real funds.

Report suspected vulnerabilities privately to the maintainers. Until a private
security address is configured, do not open an issue containing exploit details;
instead open a minimal issue requesting a private contact channel.

Supported security releases and an encrypted reporting address must be defined
before the first public production release. Security fixes will receive a CVE
when appropriate, a coordinated disclosure date, and a patched release.
