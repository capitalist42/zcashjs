## [Unreleased]

### Added

- Phase 0 architecture, threat model, compatibility, API, security, and release
  policies.
- npm/TypeScript monorepo with ESM packages and declaration/source-map output.
- Exact zatoshi amounts, network definitions, byte utilities, and stable errors.
- Transparent and Sapling codecs plus ZIP 316 Unified Address validation and
  backend-assisted receiver inspection.
- ZIP 321 ZEC payment URI parser and encoder.
- Bounded transaction envelope inspection for versions 1 through 5.
- Pinned Rust/Wasm F4Jumble proof of concept.
- Protocol-vector, unit, packaging, and Node-version CI checks.
- Phase 2 read-only wallet, lightwallet synchronization, reorg recovery, balance
  and history projections, IndexedDB storage, and Node SQLite storage.
- Phase 3 ZIP 317 proposals, durable note locking, PCZT role orchestration,
  broadcast, and transaction monitoring.
- Phase 4 encrypted key-store, React Native, transport-policy, telemetry, and
  full-node RPC integrations.
- Phase 5 value-pool registry, migration planning, opaque key authority, and
  threshold PCZT signing coordination.
